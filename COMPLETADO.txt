🚀 INICIO RÁPIDO
═════════════════════════════════════════════════════════════════════════════

1. Generar Tokens
   $ openssl rand -base64 32   # MCP_READ_TOKEN
   $ openssl rand -base64 32   # INSTAGRAM_SYNC_ADMIN_TOKEN

2. Configurar .env.local
   MCP_READ_TOKEN=<token>
   INSTAGRAM_SYNC_ADMIN_TOKEN=<token>

3. Compilar
   $ cd dashboard && pnpm build

4. Sincronizar Posts
   $ curl -X POST http://localhost:3000/api/instagram/sync \
     -H "Authorization: Bearer $INSTAGRAM_SYNC_ADMIN_TOKEN" \
     -H "Content-Type: application/json" \
     -d '{"action": "import"}'

5. Probar
   $ ./scripts/test-instagram-mcp.sh $MCP_READ_TOKEN

6. Desplegar en Hostinger
   $ docker build -t sweetq-mcp .
   $ docker push <registry>/sweetq-mcp

7. Conectar a ChatGPT
   Settings → Integrations → MCP Servers → Add Private Server
   URL: https://yourdomain.com/api/mcp
   Token: $MCP_READ_TOKEN
